## NextCMD Project

This is a terminal menu in Python I made a long time ago that I decided to upload.

# What does this project include?

It includes 6 different apps made by me:

- A calculator
- A basic RPG Character Creator
- An anime player
- A note manager that uses JSON files
- A typing game
- A system information app
